# Musina in Motion — presentation cue card

## Thread to remember

**Where is somebody from — and when?**

If you remember that question, you can reconstruct the whole talk without memorising every sentence.

## Seven moves

1. **Atlas** — one map cannot carry the whole argument.
2. **Hinge** — Musina connects mobility systems; it is not simply an endpoint.
3. **Time changes origin** — birthplace and recent origin produce different regional geographies.
4. **Scale changes the pattern** — local wards contain different combinations of settlement and circulation.
5. **Near ≠ accessible** — GIS measures proximity, not the whole access chain.
6. **The map has blind spots** — 128 resources named; 39 with coordinates; 37 in the core map. What GIS cannot see is also evidence.
7. **Put time back in** — narrated journeys restore interruption, work, return and changing place-meaning.

## Four lines worth learning almost verbatim

> “The map did not invent a new finding; it made the structure of an existing finding visible.”

> “Mobile where, and in what way?”

> “Am I showing you the resource system, or the part of the resource system that GIS can see?”

> “Our survey maps compress lives. The narrated journeys put time back into geography.”

## Final landing line

> “Geography has not simply illustrated the Musina research; it has helped us see structure in the evidence that would otherwise be much easier to miss.”
